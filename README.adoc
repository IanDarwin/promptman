# PromptMan, the AI Prompt Manager

A desktop application for storing, searching, and managing AI prompts.
Implemented in Java Swing.

---

## Running the app

You need **Java 21** (or later) installed. Not tested with any earlier releases.

```bash
java --enable-native-access=ALL-UNNAMED -jar promptman.jar
```

Where `promptman.jar` is downloaded from https://github.com/IanDarwin/promptman/releases/latest[]
or built from source as described below. Actual file will have a version number.

A full installer (including minimized JRE) for various OSes will be available in the `releases` folder, someday.

This app creates `~/.prompt-manager/` on first run, containing:
- `prompts.db` — hsqldb database (auto-created with schema)
- `settings.properties` — persisted settings

## Building from source

Requires Maven 3.x and Java 21.

```bash
mvn package
java -jar target/prompt-manager.jar
```

The Maven build produces a self-contained fat JAR with dependencies bundled.

### OpenBSD/NetBSD/FreeBSD note

Current versions of jtess (Java Tesseract), the OCR software, uses a library called JNA
(hopefully someday they will move to using Java 25's FFI instead).
I've declared in the POM a later version than the one they use,
and on non-mainstream OSes you have to install it. 

On OpenBSD, the process is below. On other OSes YMMV.

	# Make sure both BSD-specific pieces are present.
	doas pkg_add tesseract jna
	# Install the BSD-specific JNA in our ~/.m2/repo for use instead of the one from Maven Central
	mvn install:install-file -Dfile=/usr/local/share/java/classes/jna-jpms.jar \
		-DgroupId=net.java.dev.jna -DartifactId=jna -Dversion=5.18.0 -Dpackaging=jar \
		-DlocalRepositoryPath=lib -DcreateChecksum=true

The POM file is already configured to use this.

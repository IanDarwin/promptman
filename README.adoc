# AI Prompt Manager

A desktop application for storing, searching, and managing AI prompts.
Implemented in Java Swing.

---

## Running the app

You need **Java 21** (or later) installed.

```bash
java -jar prompt-manager.jar
```

The app creates `~/.prompt-manager/` on first run, containing:
- `prompts.db` — hsqldb database (auto-created with schema)
- `settings.properties` — persisted settings

## Building from source

Requires Maven 3.x and Java 21.

```bash
mvn package
java -jar target/prompt-manager.jar
```

The Maven build produces a self-contained fat JAR with sqlite-jdbc bundled.
